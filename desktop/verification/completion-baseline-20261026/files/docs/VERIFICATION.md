## Remaining boundaries

Windows x64 portable, unsigned, no system-wide installer. Keep the entire executable folder together. Authentication uses the app's own session and can require manual sign-in again; no unattended-login guarantee. The current live result was one grid; recognized ASP.NET paging is unit tested, but exhaustive live multi-page coverage is not claimed. Unknown site changes may need adapter updates. Date-only end-of-day is a disclosed local convention, not a verified server timestamp. Storage is a single-owner atomic JSON file with file-fsync/rename, not a cross-process database or an absolute power-loss guarantee. No task mutation, scheduler, telemetry or remote publication was installed.

## Scope boundaries

The original report is imported and labeled historical. A failed or offline sync never turns it into live data. Browser sign-in occurs only through the official PES page. No password is copied from Hermes, no task is mutated, no recurring job is installed and no remote publication is performed.

The package is unsigned and portable unless later evidence explicitly establishes signing or installation. Windows security prompts can therefore occur; no signing claim is made.
